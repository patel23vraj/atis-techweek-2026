## Add yourself (Challenge 3.1)

You can't edit this repo directly, so you'll make your own copy (a **fork**), add your file there, and ask us to pull it in.

1. Click **Fork** (top right of this page) → **Create fork**.
2. In **your fork**, click **Add file** → **Create new file**.
3. Name it `members/your-username.md`, using your real GitHub username. The `/` creates the folder.
4. Copy the layout from [`members/your-name.md`](members/your-name.md) and fill in your name, major, a fun fact and your site link.
5. Click **Commit changes**.
6. Click **Contribute** → **Open pull request** → **Create pull request**.

**Done when:** your pull request shows on *this* repo's **Pull requests** tab (not on your fork). We'll review and merge it live.

Please only add your own file. Don't edit other people's files or this README.

## Review a classmate (Challenge 3.2)

1. Open the **Pull requests** tab on this repo.
2. Open a classmate's pull request → **Files changed**.
3. Hover over a line and click the blue **+**.
4. Leave a kind, specific comment → **Add single comment**.

Good: *"Your site link is missing `https://`, so it won't open."* Not so good: *"looks bad."*

## Report a bug (Challenge 3.3, bonus)

Find something to improve on a classmate's site. Open **their** repo → **Issues** → **New issue**, give it a clear title, and describe the problem.

## Finish at home: Round 2 challenges

These happen in **your own** `your-username.github.io` repo.

**2.1 Ship a feature the professional way.** Add a "My Projects" or "My Hobbies" section using a branch and a pull request. Never edit `main` directly.
- Hint 1: Make a branch first (the button on the Code tab that says `main`).
- Hint 2: Edit `index.html` on your branch and commit.
- Hint 3: Click the yellow **Compare & pull request** banner, create the PR, then **Merge pull request**.

**2.2 Make it yours.** Change your site's colors and add at least one link (LinkedIn, Instagram or a favorite site).
- Hint 1: Colors live inside the `<style>` section near the top.
- Hint 2: Try `background: #f4f4f4;` inside `body { }`.
- Hint 3: A link looks like `<a href="https://...">Text</a>`.

**2.3 Add a photo (bonus).** Upload an image with **Add file → Upload files**, then add `<img src="photo.jpg" width="200">` using your exact file name.

**2.4 Cause and fix a merge conflict (bonus).** Make two branches that change the same line of `index.html` differently. Merge one, then the other. GitHub shows `<<<<<<<`, `=======` and `>>>>>>>` markers: keep the version you want, delete the markers, then **Mark as resolved**.
